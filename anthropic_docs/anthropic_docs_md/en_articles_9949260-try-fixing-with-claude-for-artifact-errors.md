# “Try fixing with Claude” for artifact errors

**Source:** https://support.claude.com/en/articles/9949260-try-fixing-with-claude-for-artifact-errors

"Try fixing with Claude" is designed to help you quickly address any errors that are detected when generating artifacts. This feature provides an easy way to prompt Claude to attempt to fix the error, streamlining the troubleshooting process.

# How it works

When an artifact generates an error:

1. Look for the "Try fixing with Claude" button near the error message.
2. Click the button to automatically copy the error details into a new message in your conversation.
3. Send the message to Claude, who will attempt to diagnose the issue and suggest a fix.

**Note:** While Claude will attempt to fix the error, success is not guaranteed. Some errors may require additional troubleshooting or human intervention. Always review Claude's suggested fixes carefully to ensure they align with your intended functionality.
