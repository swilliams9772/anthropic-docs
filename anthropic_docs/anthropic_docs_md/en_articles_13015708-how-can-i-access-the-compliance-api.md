# How can I access the Compliance API?

**Source:** https://support.claude.com/en/articles/13015708-how-can-i-access-the-compliance-api

The Compliance API is generally available to Enterprise plans.

Enterprise plan Primary Owners can enable the Compliance API by navigating to [Admin settings > Data and privacy](https://claude.ai/admin-settings/data-privacy-controls) and clicking "Enable" under **Compliance API**:

[![](https://downloads.intercomcdn.com/i/o/lupk8zyo/1867698671/7de0faeaeae2a33d643970217689/619625b9-e2d9-4109-a76b-dfeb610be463?expires=1767998700&signature=062bd968bba229c991e68b19e8bb2346adc16c2257fe5f76c2a8c191d3ec7cd6&req=dSghEc93lYdYWPMW1HO4zbwCHBwqpsdLgysy9He2G7FPHqcxzB9N5LnX0CTX%0AwTWqOunKxHEvzvcGhpw%3D%0A)](https://downloads.intercomcdn.com/i/o/lupk8zyo/1867698671/7de0faeaeae2a33d643970217689/619625b9-e2d9-4109-a76b-dfeb610be463?expires=1767998700&signature=062bd968bba229c991e68b19e8bb2346adc16c2257fe5f76c2a8c191d3ec7cd6&req=dSghEc93lYdYWPMW1HO4zbwCHBwqpsdLgysy9He2G7FPHqcxzB9N5LnX0CTX%0AwTWqOunKxHEvzvcGhpw%3D%0A)

Once the Compliance API is enabled, create new compliance access keys by clicking "+ Create key":

[![](https://downloads.intercomcdn.com/i/o/lupk8zyo/1867701300/8a148e524f7ac2b1295d87005656/bd069690-3edf-4c51-ab66-09c73db81328?expires=1767998700&signature=8043b88d7f8eb11a75c34fe8f1694e10e772953117e89ef5678211b71d5b5286&req=dSghEc5%2BnIJfWfMW1HO4zdjcNU810MUULb9AVN3cSSEMY%2FvyuWKD0uPL7ipa%0AWrPYjZP60FsJ260aI2s%3D%0A)](https://downloads.intercomcdn.com/i/o/lupk8zyo/1867701300/8a148e524f7ac2b1295d87005656/bd069690-3edf-4c51-ab66-09c73db81328?expires=1767998700&signature=8043b88d7f8eb11a75c34fe8f1694e10e772953117e89ef5678211b71d5b5286&req=dSghEc5%2BnIJfWfMW1HO4zdjcNU810MUULb9AVN3cSSEMY%2FvyuWKD0uPL7ipa%0AWrPYjZP60FsJ260aI2s%3D%0A)

Creating a compliance access key will allow you to start pulling activity logs, chat data, and file content programmatically.

The Compliance API doc is accessible via [our Trust Center](https://trust.anthropic.com/resources#692f35ca70113b25f1d2ec34:~:text=Request%20access-,Compliance%20API,-Anthropic%20Compliance%20API). Note that an NDA signature is required to access this.

**Note:** The Compliance API is not available to Public Sector organizations.
