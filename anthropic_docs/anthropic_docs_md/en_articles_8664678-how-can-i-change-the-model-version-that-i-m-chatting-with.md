# How can I change the model version that I’m chatting with?

**Source:** https://support.claude.com/en/articles/8664678-how-can-i-change-the-model-version-that-i-m-chatting-with

Use the model selector to switch between available models:

1. Start chatting with Claude or open an existing chat.
2. The selected model will appear under your text input.
3. To change it, click on the model name and choose which Claude model you’d like to chat with instead:

If you’ve previously messaged Claude in an existing chat, switching Claude’s model will open a new chat.
