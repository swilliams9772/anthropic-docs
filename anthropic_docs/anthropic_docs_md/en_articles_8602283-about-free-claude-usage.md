# About Free Claude Usage

**Source:** https://support.claude.com/en/articles/8602283-about-free-claude-usage

While using the free Claude plan, there is a session-based usage limit that will reset every five hours. Also, the number of messages you can send will vary based on demand, and we may impose other types of usage limits to ensure fair access to all users. Claude will notify you when you’ve reached your usage limit, or if your prompt exceeds the available context window.

# How do I increase my usage limits?

We also have several paid subscriptions that offer additional usage. View our guide on [Choosing a Claude Plan](https://support.anthropic.com/en/articles/11049762-choosing-a-claude-plan) for more information.
