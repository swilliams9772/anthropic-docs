# Usage Analytics for Enterprise Plans

**Source:** https://support.claude.com/en/articles/12883420-usage-analytics-for-enterprise-plans

This article explains how to view and export usage analytics for your Enterprise plan organization.

**Note:** Only Enterprise plan Owners can access usage analytics.

Usage analytics help you track team activity, feature adoption, and spend directly from your admin dashboard. You can monitor how your organization uses Claude and export detailed reports for your own analysis.

Primary Owners and Owners can access analytics via [Admin settings](https://claude.ai/admin-settings/analytics-activity) by clicking "All activity" under **Analytics**. Additionally, the "Claude.ai" and "Claude Code" options offer product-specific analytics.

**How to export user-level spend data:**

You can export user-level spend as a CSV file for your own reporting by following these steps:

1. Navigate to [Admin settings > All activity](https://claude.ai/admin-settings/analytics-activity).
2. Scroll down to the **Spend** section.
3. Locate the "Export Spend Report" option:

   [![](https://downloads.intercomcdn.com/i/o/lupk8zyo/1841509123/4d407dd6ab6849dab4060d0d7ff2/d4a0dd87-84fb-4ca3-8a83-621b21bcb1b9?expires=1767998700&signature=f5a398b0573aede7d58089d8e68ce66c492f223005fe2341324d6d3cd12c882d&req=dSgjF8x%2BlIBdWvMW1HO4zRUd%2FaSXz1nl9yTEpp8H3leDzu3OAdJaaI32RKQ9%0Ay7j6%0A)](https://downloads.intercomcdn.com/i/o/lupk8zyo/1841509123/4d407dd6ab6849dab4060d0d7ff2/d4a0dd87-84fb-4ca3-8a83-621b21bcb1b9?expires=1767998700&signature=f5a398b0573aede7d58089d8e68ce66c492f223005fe2341324d6d3cd12c882d&req=dSgjF8x%2BlIBdWvMW1HO4zRUd%2FaSXz1nl9yTEpp8H3leDzu3OAdJaaI32RKQ9%0Ay7j6%0A)
4. Select the data you want to export.
5. Download the CSV file.
